## 💻 `terminal@ganesh-devops:~$ whoami`

> **DevOps & Cloud Infrastructure Engineer** focused on building resilient cloud architectures, automated CI/CD pipelines, container orchestration, and shift-left security workflows.

- ☁️ **Cloud Architecture:** Designing and deploying scalable infrastructure on **AWS**.
- 🔄 **CI/CD Automation:** Engineering robust build and release pipelines using **Jenkins, Git, & GitHub**.
- 🏗️ **Infrastructure as Code:** Provisioning immutable environments via **Terraform**.
- ⚙️ **Configuration Management:** Automating server provisioning and orchestration with **Ansible**.
- 🐳 **Containerization:** Packaging microservices using **Docker** and managing container images.
- ☸️ **Orchestration:** Deploying and scaling workloads using **Kubernetes (K3s / Minikube)** and **Helm**.
- 🔒 **DevSecOps & Secrets:** Implementing shift-left security (Gitleaks, SonarQube, Trivy) and enterprise secrets management with **HashiCorp Vault**.
